STATIC GESTURES
---------------
open        — index + middle + ring + pinky extended (thumb state ignored)
fist        — index + middle + ring + pinky curled (thumb state ignored)
thumbs_up   — thumb extended and away from palm, all other fingers curled; also triggered by thumb + pinky
thumbs_down — same as thumbs_up but thumb pointing downward
ok          — middle + ring + pinky extended, index curled to touch thumb tip (pinch < 35% palm width)
point       — index extended, others curled
peace       — index + middle extended, others curled
unknown     — none of the above matched

DYNAMIC GESTURES (open hand only, must start from frame center)
----------------------------------------------------------------
wave        — hand oscillates left-right (5+ direction changes, span > 25% of frame)
swipe_left  — fast move leftward (mirror-corrected for front camera)
swipe_right — fast move rightward (mirror-corrected for front camera)
swipe_up    — fast move upward
swipe_down  — fast move downward
push        — hand grows quickly toward camera (size increase > 0.08)
